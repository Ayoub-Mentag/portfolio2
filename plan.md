# Portfolio Plan

## Direction

A simple, reliable portfolio that clearly identifies who I am and shows the work I have done. It should be easy to browse and avoid vague claims or presenting me as an expert in everything.

I am a software engineer with full-stack experience on production applications and an interest in system design, software architecture, and design patterns. Small businesses looking to build digital systems are the intended audience, but the introduction should describe me rather than read like a sales pitch.

## Page structure

1. Introduction
2. Projects
3. Get in touch

There will be no About section.

## Introduction

- Profile image
- My name
- A short description beneath my name:

> Full-stack developer building for the web, from start to ship.

Place a small animated ship next to the word “ship.”

## Projects

### Layout

Each project includes:

- Project name
- A short description
- A project image next to the text
- A small row of tech icons with names beneath the description

Use a consistent two-column layout on desktop, with the text on the left and image on the right. On mobile, stack the name, image, and description, followed by the tech stack.

Keep entries concise. No team-project labels or separate contribution descriptions are needed.

### Transcendence

A Pong web app with login, offline play against a bot, and online matches. A leaderboard tracks player rankings.

**Tech stack:** Next.js · NestJS · Prisma · PostgreSQL · Docker · Docker Compose

### Music Room

A mobile app where users create events, add tracks, and vote for what plays next. Users can also manage public or private playlists and import them into events.

**Tech stack:** Flutter · NestJS · Redis · PostgreSQL · Docker Compose

### GitOps Deployment Lab

A Kubernetes cluster with GitLab and Argo CD, configured to automatically deploy updates when a new version is pushed to the repository.

**Tech stack:** Kubernetes · Argo CD · GitLab

Former project name: Inception of Things. Use **GitOps Deployment Lab** in the portfolio.

### Local Coding Assistant

A coding assistant that runs locally with Ollama, without paid API calls. Uses retrieval-augmented generation (RAG) to bring relevant context into coding conversations.

**Tech stack:** Ollama · Python

Former project name: Inception of Context. Use **Local Coding Assistant** in the portfolio.

### Red Tetris

A Tetris game with login, solo play, and online multiplayer, featuring rock obstacles for an extra challenge.

**Tech stack:** React · Redux · Express.js
